Sistema de inventario para un taller de suspensiones

Proyecto universitario en Java (POO).

Aplicación de escritorio para gestionar el inventario de un taller de suspensiones automotrices. Usa herencia (Vehículo y CarroH), una clase abstracta Suspension con tres tipos (hidráulica, neumática y mecánica) que aplica polimorfismo, y una interfaz gráfica en Java Swing para registrar y consultar vehículos.
